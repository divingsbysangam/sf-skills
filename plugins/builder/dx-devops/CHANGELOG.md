# Changelog

All notable changes to this plugin are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this plugin adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.3.0] — 2026-10-30

### Changed

- Updated skills: `dx-devops-conflict-resolve`, `dx-devops-pipeline-manage`, `dx-devops-project-manage`, `dx-devops-work-item-manage`.

## [0.2.0] — 2026-09-21

### Added

- Create, list, and update DevOps Center projects (`dx-devops-project-manage`).
- Diagnose and resolve the merge conflicts and deployment failures that block a work item's
  promotion (`dx-devops-conflict-resolve`).

## [0.1.0] — 2026-08-24

### Added

- Initial release. Manage DevOps Center pipelines (`dx-devops-pipeline-manage`) and work items
  (`dx-devops-work-item-manage`), configure test pipelines (`dx-devops-test-pipeline-configure`)
  and suite assignments (`dx-devops-test-suite-assignments-configure`), run stage test suites
  (`dx-devops-test-suite-run`), and analyze test failures (`dx-devops-test-failures-analyze`).
