# Changelog

All notable changes to this plugin are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this plugin adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.3.0] — 2026-10-30

### Changed

- Updated skills: `platform-widget-generate`.

## [0.2.0] — 2026-09-21

### Added

- `platform-widget-generate` now supports formula expressions in widget bindings, string
  interpolation, and `meta.if` conditions.

## [0.1.0] — 2026-08-24

### Added

- Initial release. Generate custom Lightning Types (`platform-custom-lightning-type-generate`),
  coordinate Apex-backed Lightning Type widgets (`platform-lightning-type-widget-coordinate`) and
  MCP tool result widgets (`platform-mcp-tool-widget-coordinate`), and generate rich display
  widgets for agent actions (`platform-widget-generate`).
